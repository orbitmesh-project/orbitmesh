# Official Packages

These are maintained alongside OrbitMesh itself. Install any of them from the Console's "Online Package Repository" if your Server is pointed at a feed that carries them.

| Package | Description |
| --- | --- |
| **DayInfo** | Sunrise/sunset (NOAA solar calculator) and French name-day (almanac) info - no external API. |
| **ForecastIO** | Global weather service, built on Open-Meteo (free, keyless). |
| **NetworkTools** | Ping, TCP port scanner/check, HTTP check, Wake on LAN, DNS lookup and monitoring. |
| **OpenWeather** | Weather service based on the OpenWeatherMap v2.5 API (free tier). |
| **SonyBravia** | Control Sony Bravia devices (IRCC-IP + Pre-Shared Key). |
| **Spotify** | Now-playing and volume control for Spotify via the official Web API. |
| **TPLinkSmartHome** | Discover and control TP-Link Kasa/Tapo devices on the local network. |
| **Waze** | Paths and travel times from Waze's live-map routing service. |

Want to write your own? See [Building a package](/guide/sdk/).
