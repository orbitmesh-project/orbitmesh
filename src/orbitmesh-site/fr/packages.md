# Packages officiels

Ces packages sont maintenus au même endroit qu'OrbitMesh. Installez-les depuis le "Online Package Repository" de la Console si votre Server pointe vers un feed qui les héberge.

| Package | Description |
| --- | --- |
| **DayInfo** | Lever/coucher du soleil (calcul NOAA) et almanach des prénoms français - aucune API externe. |
| **ForecastIO** | Service météo mondial, reconstruit sur Open-Meteo (gratuit, sans clé). |
| **NetworkTools** | Ping, scanner/vérification de ports TCP, vérification HTTP, Wake on LAN, résolution DNS et monitoring. |
| **OpenWeather** | Service météo basé sur l'API OpenWeatherMap v2.5 (offre gratuite). |
| **SonyBravia** | Contrôle des téléviseurs Sony Bravia (IRCC-IP + clé pré-partagée). |
| **Spotify** | Lecture en cours et contrôle du volume Spotify via l'API Web officielle. |
| **TPLinkSmartHome** | Découverte et contrôle des appareils TP-Link Kasa/Tapo sur le réseau local. |
| **Waze** | Itinéraires et temps de trajet via le service de routage live de Waze. |

Envie d'écrire le vôtre ? Voir [Créer un package](/fr/guide/sdk/).
